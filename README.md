# 丁昶视角·研究顾问

一个基于丁昶公开作品整理的 Agent Skill。遇到投资或经营问题时，让这个视角成为讨论中的一位顾问：从哪里入手，因果链怎样成立，依赖什么假设，什么证据会改变判断。

**它是有来源的思维辅助，不是丁昶本人、官方授权产品或投资决策代理。** 作者作品提供观察起点，具体问题的应用推断由使用者及模型承担。

## 能帮你做什么

- 从规模、利润和市场叙事，追到现金兑现、必要追加投入和受益人。
- 换到关键主体的位置，理解目标、约束与成本分配。
- 查找观点的公开出处、历史时点与适用条件，保留无法解释的版本差异。
- 提出有条件的倾向、最强反方和改判证据，供你与其他顾问比较。

它没有实时行情、作者私有资料或自动交易能力；对当前公司和市场事实仍需独立查询。书籍入口可能需要合法购书或会员，本仓库不包含书籍、文章、音频全文及访问凭据。

## 安装与调用

本仓库根目录就是一个Skill目录，入口是[SKILL.md](SKILL.md)。支持此目录格式的工具可以使用；实际自动发现规则依工具而异。

Codex本地安装示例（已有同名目录时先比较内容，不覆盖）：

```sh
mkdir -p ~/.codex/skills
git clone https://github.com/iamvivianopenclaw-oss/dingchang-investment-research.git ~/.codex/skills/dingchang-investment-research
```

在加载该Skill目录的新会话中显式调用，例如：

```text
请用 $dingchang-investment-research 分析下面的经营选择。
我希望理解推理，不只是得到结论。请区分作者依据、当前事实与本次推断，
指出决定性假设，再用一个最强反方质疑它。没有独特帮助就直接说。

问题：[你的真实问题]
已知材料：[公开原始资料或你有权提供的材料]
判断对象与时间尺度：[为谁、判断什么、看多久]
```

如果工具未发现该Skill，可以明确提供安装后的`SKILL.md`路径。需要查原话时直接提出出处/时点问题即可，无须同时要求投资建议。上面的安装是文档说明；本次发布未在所有工具或全新设备上验证自动发现。

## 没有原始资料，下载后怎么学

从[文章论证卡](references/article-arguments.md)选一个问题，或看[银行论证卡](references/bank-argument.md)。每张都说明作者的问题、论证、研究者重构的假设、反例、迁移方式和出处。卡片是原创释义，不是作者原文或训练后的模型权重。

再读两个真实案例：[星巴克合资](references/case-starbucks.md)说明如何形成可质疑的意见；[房地产竣工预测](references/case-housing.md)保留一个不支持历史预测强解释的结果。它们包含足够理解案例的事实与来源，不依赖维护者的私人笔记；合同、原声等未取得之处仍明确留空。

断网时可学习和应用已打包的历史框架，不能据此声称核验了原话、取得全书或掌握作者最新立场。需要精确引用或最新现实判断时，再补相应原材料。

## 一个提问示例

面对“出售门店多数股权、保留品牌授权和少数股权是否划算”，可以先追问：

> 品牌费、供货款、股权分红分别什么时候能收到？扩张与偿债的钱由谁出？停止继续投入会失去什么？

这能把“轻资产了”拆成可核对的现金路径。它本身不能证明交易好坏：仍需将一次性净所得、后续现金、剩余权益和潜在义务，与继续经营比较。这个例子是研究者应用，不是作者针对某公司的原话，也不是其他分析方法不会提出的问题。

## 来源与边界

- [思维起点](references/thinking-framework.md)：作者明示、研究者归纳、迁移边界分开。
- [公开证据路由](references/evidence-map.md)：作品、日期、公开链接、定位与读取限制。
- [专项条件](references/conditional-checks.md)：银行、估值、版本差异及持有/退出未决项。
- [试用观察与局限](EVALUATION.md)：正面、小幅增量、无差异及不足一起保留。

主要依据包括《自由与现金流》《面壁与破壁》《AI三问》和《买入银行股》。外部网页可读性与来源授权等级不是一回事；《AI三问》所列转载的授权状态未确认。网站的转载授权也不代表作者授权了本Skill。
