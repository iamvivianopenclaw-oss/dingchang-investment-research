# 案例一｜星巴克中国合资：轻资产是否等于股东更划算？

**性质：真实事件上的研究者迁移示范，不是丁昶评论过该交易。**这是编制者综合旧首答与审查后的教学稿，不能当作某一版Skill独立发现，也不是一次新的盲测。资料截面截至2026-06-28的公司10-Q，本次2026-10-14核阅相关段落；不代表后续全量尽调。

## 足够理解问题的事实

- Starbucks在SEC提交的10-Q，Note 2记载2026-03-30完成中国零售业务处置：博裕取得60%，约40亿美元为无现金无债务企业价值；总对价31亿美元包含星巴克应占新合资公司借款所得。[10-Q，Note 2](https://www.sec.gov/Archives/edgar/data/829224/000082922426000130/sbux-20260628.htm)
- 公司2026-04-02公告说明星巴克保留40%，继续拥有并授权品牌和知识产权。公告日与上述完成日分开。[交割公告，交易条款段](https://about.starbucks.com/press/2026/starbucks-and-boyu-capital-finalize-joint-venture-to-accelerate-long-term-growth-in-china/)

**待判断：**站在星巴克长期普通股股东一侧，出售方案是否优于继续直营？“卖出多数股权”本身不回答这个问题。

## 怎样从作者的观察起点走进这个问题

[论证卡A1](article-arguments.md)提供现金兑现与持续投入的观察起点；[A2](article-arguments.md)提示换主体理解目标。把它们迁到交易合同，是研究者应用。以下收款划分、估值和治理核查属于通用金融分析，并非作者独创。

1. **先拆收款。**一次性交易所得、品牌授权净现金、可能的供货净现金、40%股权分配，是不同路径。收到其中一笔，不证明其他路径也顺畅；供货安排、费率、实际收款和净利润都须另核，不能把销售额当净收益。
2. **追谁必须继续付钱。**合资企业仍需要经营、投入并偿债。母公司收款，不等于整个业务去杠杆；权益法利润也不等于合资企业已现金分红。实际支付次序要看合同，不能宣称品牌费天然优先。
3. **看能否停止以及代价。**保留少数股权可能减轻直接经营负担，但未核追加出资、担保、控制权与退出条款前，不能把40%当成免费期权。品牌损伤也不一定局限于合资公司的损失。
4. **比较完整选择。**在同一时点比较“税后一次性净所得＋未来净现金现值＋剩余权益价值”与继续直营的相应价值，计入各自投入、义务和风险；后续现金与终值不重复算。31亿美元含借款所得，不能直接除以60%当作纯股权售价反推。还债用途与所得也不能重复创造一份价值。

## 有条件的判断与真正的反方

**条件倾向：**若伙伴提升门店经济性，星巴克可持续收到净现金，又没有保留接近原直营的隐性资金义务，交易存在正面机制。但缺完整合同、独立现金流和可信直营比较方案，净增值仍未证实。

**最强反方：**一次性收款可能换走了更有价值的长期上行；失去经营控制后仍承担品牌风险。另一面，暂不分红也可能是在进行高回报再投资，不能只凭现金少就判失败。

**改变判断的证据：**收费实际兑现、合资企业资本投入与债务义务、追加资金责任、剩余权益的经济价值，以及继续直营可实现的回报。没有这些数据，不给净现值数字，不虚构合同。

## 好的与不好的都保留
