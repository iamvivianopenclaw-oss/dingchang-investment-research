# 思维起点、作者依据与迁移边界

以下五项是研究者对公开作品的操作化归纳，不是作者公布的五步法，也不是独创性证明。按问题选用，出处和读取限制见[证据路由](evidence-map.md)。

## 1. 从异常跨层寻找原因

**作者明示：**《AI三问》使用金融投资、实体经济、社会文明三个观察层面，从市场与经营结果的分化发问（S03，开篇）。

**迁移：**先说清需要解释的现象，再检查较近的经营、竞争、资金条件，必要时扩大到制度环境。三个层面是搜索范围，不是必须写三段。不同层面结果不一致不自动构成矛盾。

**边界：**相关性和历史相似不证明因果或未来重复；作者对部分资金流向也承认缺直接证据。此文关于产业关联的类比不能替代法定并表控制标准。

## 2. 换主体位置，追成本和收益归属

**作者依据：**《面壁与破壁》第一节“政眼看经”要求从政策制定者的目标理解行动（S02）。《买入银行股》第3章“四元模型”“社会责任谁承担”及第4章“透过现象看本质”讨论不同主体的作用（B01）。

**迁移：**谁有权改变结果？他要解决什么约束？谁付款、谁承担下行、谁取得剩余收益？从系统功能追到用户关心的受益人，中间需要补什么证据？

**边界：**书中的企业、地方政府、银行系统和中央政府关系，不能直接照套任意公司或国家。国家层面的抵销不消灭个体现金压力；系统救助不是普通股回报担保。合同、清偿、资本和每股分配核查属于通用金融补充。

## 3. 找有证据的反馈，不用周期当时钟

**作者依据：**《买入银行股》第5章“美国大循环”和第6章“融资，再融资”将估值、融资、经营及利益主体联系起来（B01）。

**迁移：**只有本题事实支持时，才建立反馈链；辨认延续所需条件、最脆弱一环和可以观察的信号。融资顺畅不能直接推出项目最终赚钱。

**边界：**一个环节减弱不必立刻触发全盘逆转；政策、资产负债表和时滞可能缓冲。历史周期长度不提供自动择时信号，没有反馈证据就保留单向解释。

## 4. 从账面成果追到兑现与选择自由

**作者明示：**《自由与现金流》第二节讨论应收款和追加投入，第三节讨论旧成功经验对选择的束缚（S01）。

**迁移：**钱什么时候真正收到？为维持现状还必须付出什么？哪些投入能停止，停止会损失什么？把账面成功与实际可支配空间分开。

**边界：**再投资也可能创造价值，削减必要投入也可能暂时美化现金。不能预设扩张是陷阱，或短期无分红就是失败。少数股权仍可能伴随义务，不能直接称为无成本选择权。银行不能套用普通工商企业的简单自由现金流公式。

## 5. 看对方向与取得回报分别判断

**作者依据：**《买入银行股》第2章讨论低估与投资价值的关系，第6章保留真正成长公司的合理溢价，第7—9章讨论估值与分配条件（B01）；《AI三问》也区分技术方向与投资问题（S03）。

**迁移：**说明回报来自经营改善、现金分配还是估值变化；同一产业判断在不同买价下可能对应不同投资结论。出售或合资方案要与继续经营的同口径方案比较，不能只看利润率。

**边界：**每股计算、机会成本、完整方案现值比较是通用分析，不归为作者独有。历史PB、股息率、仓位和期限不能成为永久交易规则；未解决的版本和持有/退出排序见[专项条件](conditional-checks.md)。
